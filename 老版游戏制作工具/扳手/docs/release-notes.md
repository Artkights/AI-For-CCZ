## 2026-10-31 单 EXE 扩展引擎适配版

本版适配工作区 `基底/Ekd5.exe`，SHA256 为 `719F710687CAE4BAEC2B3A4B028B473EA8AEB334A7ACFA6A692B46F207B5CDF8`，大小 6,200,832 字节。该样本实际属于 6.6 派生引擎，扳手中选择“自动”或“6.6”。发布文件继续使用项目既有名称 `6.6扳手.exe`。

## 修改内容

- 新增单 EXE 派生版显示身份；功能开放由机器码配方和表结构决定，SHA 只用于命名。
- 识别经 `[0x004F0008]` 转发、含 34 个 NOP 的天赋查询函数，并结合初始化与表访问锚点确认 255×16 字节的 4+2 天赋布局。
- 必杀分配通过索引、五槽查询和两处80行边界共同确认，不再依赖被停用的脚本 writer；缺少 Data.e5 时显示“必杀0”等编号，保留分配编辑。
- 人物重算识别全局开关代码被 NOP 的精确变体，保留内部调用目标、人物参数和 ret 4 的校验；移动力255改为函数内部签名，修复跨前一函数尾的漏检。
- 新增扩展消耗品配方：ID 256..511，数量表 0x00750000，256 个 UInt8 项。四个访问锚点必须共同证明同一地址和范围。
- 扩展消耗品名称与仓库装备 ID 分开处理；未取得名称时显示编号，保存数量不会截断 16 位逻辑 ID 或越过数量表。
- 缺少 Data.e5/Star.e5 时，附加流程允许从机器码已定位的运行时物品目录读取元数据。元数据只读，宝物标志仍经过目录验证；不借用其它游戏样本的数据。
- 补录已安装本地售卖比例补丁的信奈样本身份，保留旧身份和原双基底证据范围。
- 发布构建增加静态 PE32/x86 校验与 `-SkipSmoke` 参数。

## 使用

解压发布包后运行 `6.6扳手.exe`，底部保留“自动”，使用准星选择正在运行的目标游戏窗口。只把该工具当作运行中游戏的内存修改器；它没有把单独的游戏 EXE 改写成一个完整资源包。运行时物品目录尚未加载时会保留具体诊断，读档/加载资源后重新附加可重新读取。

本次未执行 `基底/Ekd5.exe`，未附加真实游戏进程，未修改原始游戏、存档或数据文件。回归包括目标静态画像、不同签名互斥、损坏锚点拒绝、必杀/重算内部调用目标校验、扩展 ID 两端读写、越界拒绝、运行时目录后备、缺少/截短必杀名称文件及原有功能测试。UI 与读写验证使用 offscreen Qt 和合成内存。

只完成静态证明的入口不代表真实游戏中的重算、复活、转向或控制补丁行为已完成实机验收；外部 DLL 的运行时指针和实际 ABI 行为仍需完整游戏环境确认。
