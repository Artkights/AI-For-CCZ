# Python 扳手补丁生命周期修复（2026-11-09）

勾选后一段时间变灰的根因是：运行时重扫仍用只认原始字节的定位规则，工具自己写入的补丁使签名失配，新画像丢失PatchSpec，界面按新能力关闭复选框。6.6原生自动回归的三个NOP站点及旧版动态调用点也会受到同类所有权问题影响。

## 最终行为

磁盘静态扫描严格验证原始字节；运行时扫描仅屏蔽补丁覆盖的目标字节，保留周围签名、候选唯一性、原生调用关系和完整指令长度验证。运行时识别完整original或完整patched；partial和foreign不形成可接管配方。运行时观测不改变静态recipe与证据指纹。

主写会话保留普通补丁和动态分配的所有权。普通补丁使用ORIGINAL、OWNED_PATCHED、EXTERNAL_PATCHED、PARTIAL、EXTERNAL_CHANGED、UNREADABLE等状态；连续三次不可读记为UNREADABLE_CONFIRMED。前两次读取失败保留最后确认的勾选值；失败发生在用户点击后的前置检查时也回退显示。界面使用READY、ENABLING、ENABLED、DISABLING、ERROR、UNAVAILABLE生命周期。

已由外部启用的完整补丁也不自动接管。调用点、stub或任一站点被外部改变时，显示地址并拒绝覆盖或恢复。部分写入、写后复读不一致、回滚或页保护恢复失败记录WRITE_FAILED；兼容模式不能绕过这些错误。单次操作仍通过既有比较、写入、复读、回滚流程完成，不将外部软件事务描述为目标进程内的原子CAS。

页面切换和激活不重建补丁画像，主会话每两秒读取已有站点检查状态。首次附加的有期限后台扫描保留，结果按附加token、PID、模块基址、会话UUID、画像世代和扫描世代校验。同一会话合并后保留原画像对象及已确认配方；未就绪数据使用已有布局重新探测。显式重新附加重新识别进程和模块。主窗口显式转发Qt激活、关闭事件，使后台任务取消、等待和会话清理实际执行。

6.6自动回归保留三个原始条件跳转与目标NOP字节，取消时恢复三个原始站点。旧版动态自动回归保留自己的调用点、stub和分配信息；只读扫描句柄不能认领或清除主写会话的租约。关闭时仍保留线程EIP在stub内禁止释放的检查。

自动复活使用附加会话的disabled、enabled、paused状态和错误信息；失败后暂停、保持复选框可选，重新勾选清空去重记录。远程线程超时仍遵守既有熔断规则，不能通过反复点击提交未知状态的远程线程。手动战场复活用try/finally只在调用期间禁用按钮。
